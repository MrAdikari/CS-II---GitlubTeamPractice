GitHub Team Practice
This project will give students insight into how to use GitHub from the terminal and mimic real-world software development environments.

Assignment Instructions
Step 1: Clone the Repository
Clone this repository to your local machine.

git clone <repository-url>
Step 2: Create a Personal Branch
Create and switch to a branch using your first and last name.

Example:

git checkout -b john-smith
Step 3: Create Your Introduction File
Create a file named:

firstname-lastname.md
Include the following information:

Full Name
Major
Career Goal
Fun Fact
Example:

# John Smith

**Major:** Computer Science

**Career Goal:** Software Developer

**Fun Fact:** I enjoy hiking and playing basketball.
Step 4: Commit Your Changes
Stage and commit your work using a meaningful commit message.

git add .
git commit -m "Added introduction file"
Step 5: Push Your Branch
Push your branch to GitHub.

git push origin your-branch-name
Step 6: Create a Pull Request
Create a Pull Request (PR) from your branch to the main branch.

Step 7: Review a Classmate's Pull Request
Leave constructive feedback on at least one classmate's Pull Request.

Step 8: Merge Changes
After approval, merge your Pull Request into the main branch.

Deliverables
Each student must submit:

One personal branch
One introduction file
At least one successful commit
One Pull Request
One peer review comment
One merged contribution
Learning Objectives
By completing this activity, students will:

Learn Git and GitHub fundamentals
Use Git from the command line
Practice branching and merging
Create and manage Pull Requests
Participate in peer code reviews
Experience real-world software development workflows
